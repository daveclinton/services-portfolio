## What this post tests

We are testing four things in one place:

1. Multi-language code snippets with syntax highlighting
2. Illustration and diagram rendering in the content column
3. Social screenshot presentation (Twitter/X style)
4. Captions and spacing behavior for media blocks

## JavaScript / TypeScript snippet

```ts
export async function deployService(serviceName: string) {
  const result = await fetch(`/api/deploy/${serviceName}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
  })

  if (!result.ok) {
    throw new Error(`Deploy failed for ${serviceName}`)
  }

  return result.json()
}
```

## Python snippet

```python
def recommend_batch_size(vram_gb: int, model_scale: str) -> int:
    baseline = {"small": 64, "medium": 32, "large": 16}
    factor = max(1, vram_gb // 8)
    return baseline.get(model_scale, 16) * factor
```
