# Professional Knowledge Base

This repository is the source of truth for David Clinton's professional
experience, projects, skills, and supporting evidence. It is structured for
reuse in portfolios, case studies, CVs, proposals, and interviews.

## Start here

- [`knowledge/person/profile.md`](knowledge/person/profile.md) — canonical bio
- [`knowledge/experience/`](knowledge/experience/) — employment and consulting
  engagements
- [`knowledge/projects/`](knowledge/projects/) — detailed project records
- [`knowledge/skills/`](knowledge/skills/) — reusable capabilities
- [`knowledge/evidence/`](knowledge/evidence/) — evidence spanning multiple
  roles or projects

## Record model

Each experience has five standard records:

1. `overview.md` — company, role, dates, context, and concise narrative
2. `responsibilities.md` — work performed and ownership
3. `projects.md` — links to project records
4. `technologies.md` — tools demonstrably used during the engagement
5. `accomplishments.md` — defensible outcomes and claims

Each project has an `overview.md` and `evidence.md`. Evidence is classified as:

- `confirmed` — supported by a URL, file, artifact, or direct primary evidence
- `probable` — credible firsthand claim awaiting a source

Market research and tools that merely existed during a role are context, not
personal experience. They must not be added to `technologies.md` unless there is
evidence that David used them.
