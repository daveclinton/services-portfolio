David helps Mika's employees spend less time on repeated work, find answers in
company records and keep those records correct, so they can serve customers across
Kenya, Uganda and Rwanda. He talks to the people doing the work, builds what they
need and supports it afterwards.

## How the work is done

- Architected multi-tenant warehouse, eWarranty, after-sales, attendance/HR,
  analytics, and automation services using Django/DRF and FastAPI.
- Built role-based warehouse mobile flows for Picker, Mantrap and Admin users with Kotlin, Jetpack Compose, Material 3, Navigation Compose, Hilt, Retrofit/OkHttp and DataStore.
- Integrated Honeywell Data Collection Intent/AIDC scanner APIs for dedicated
  EDA-class warehouse devices, with scanner claim/release/control lifecycle,
  barcode broadcasts, device detection, and tested scan-feedback behavior.
- Added CameraX and bundled ML Kit barcode scanning as an in-app scanning path,
  plus Firebase Cloud Messaging for warehouse notifications.
- Integrated the Android app with the production warehouse backend through
  Retrofit, OkHttp, Moshi, authenticated API sessions, environment-specific
  endpoints, secure token storage, offline queues, and network diagnostics.
- Implemented warehouse-presence geofencing with Google Play services,
  background-location permission policy, boot/update re-registration, durable
  WorkManager retries, and offline event upload.
- Built GitHub Actions release automation that signs APK/AAB artifacts, derives
  collision-safe CI version codes, distributes builds through Firebase App
  Distribution, and publishes to closed or production Google Play tracks.
- Used Google Cloud Workload Identity Federation for short-lived CI credentials
  and built a separate Play recovery workflow for targeted in-app update prompts.
- Built React/Next.js, Vue/Vite, and Angular dashboard surfaces with TypeScript,
  Tailwind CSS, shadcn/ui, TanStack Query, Pinia, and charting libraries.
- Connected SAP Business One Service Layer, SAP HANA, MSSQL, PostgreSQL and Redis for inventory, warranty, service and reporting data.
- Built Wialon-to-SAP fleet synchronization and reconciliation with idempotency,
  watermarks, retries, dry runs, transactional writes, and scheduled execution.
- Built product scraping and asset-processing pipelines mapped to SAP item codes
  and prepared assets for S3-compatible DigitalOcean Spaces storage.
- Integrated Firebase/FCM, Africa's Talking SMS, Meta WhatsApp/WAHA, SendGrid,
  and S3-compatible object storage into operational workflows.
- Built and maintained Linux deployments with Nginx reverse proxying, systemd
  services and timers, Gunicorn/Uvicorn processes, Docker Compose dependencies,
  PostgreSQL backups, health checks, logs, release symlinks, and rollback.
- Configured internal DNS, LAN/DMZ routing, TLS termination boundaries, CORS and
  trusted-host policies, UFW rules, HTTP proxy headers, Unix sockets, and TCP/SSH
  connectivity tests for on-premise systems and devices.
- Built an AI assistant in production that answers staff questions with live
  company data and asks for approval before changing anything.
- Built the last-mile delivery, after-sales, showroom, consignment, marketplace
  pricing and messaging modules in the main platform.
- Automated order entry between group companies, with previews, run logs and
  review of unusual cases.
- Took over the outlet and repair systems from a previous developer, support them
  in production and wrote a handbook for the people who run them.
- Work directly with finance, warehouse, shop and repair teams without a product
  manager in between.
- Manage the self-hosted infrastructure and on-premise data-center environment
  to which the applications are deployed.
