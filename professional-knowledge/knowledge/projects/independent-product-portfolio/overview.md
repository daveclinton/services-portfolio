## Aqua Prana

- Next.js/React public platform and administration dashboard.
- Expo/React Native iOS and Android app with EAS build and submission profiles.
- Rust/Axum/Tokio API backed by PostgreSQL and Redis.
- Implemented integrations: OpenRouter streaming chat, Google Sign-In, Resend,
  Expo Push API, FCM/APNs, Mapbox, Upstash Redis and Vercel Blob.

## Seep Baby

- Expo/React Native connected-device app with BLE and Bluetooth Classic,
  calibration, audio and AI-assisted workflows.
- Clerk and Google identity integration, secure device-side storage, React
  Query and Zustand state patterns.
- Next.js companion product using OpenAI AI SDK, Better Auth, Prisma and
  Three.js/React Three Fiber.

## SnapList

- Next.js product using Supabase authentication, database, storage, realtime
  and server-side helpers for marketplace account and data workflows.
