Investor dashboard and public website built with Next.js and React, plus
deployed and customized Apache Superset for internal data exploration and
real-time dashboards at Untapped Global.

As part of the frontend team, converted Figma designs into production
interfaces and built reusable React chart plugins for Apache Superset. Published
three packages to npm: `superset-custom-design`,
`superset-plugin-chart-customized`, and `superset-plug-line-chart-tabs`.
