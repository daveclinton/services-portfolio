Deploying web, backend, administrative, and mobile products through AWS,
Vercel, Firebase, Google Play, and Apple's App Store. AWS experience includes
compute instances, load-balanced API environments, S3 object storage,
CloudFront CDN delivery, Docker Compose, PostgreSQL, Gunicorn, Nginx,
self-hosted GitHub Actions runners, health checks, backups, and rollback-ready
image tagging.
