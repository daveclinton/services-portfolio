## Published work

1. **PyTorch: The Ultimate Tool for Computer Vision Experts** — PyTorch
   fundamentals, tensors, datasets/data loaders, torchvision, CNN/ResNet
   concepts and custom computer-vision workflows.
2. **How to maximize GPU utilization by finding the right batch size** —
   profiling and batch-size experiments in Jupyter using PyTorch and Keras,
   including memory, convergence and multi-GPU tradeoffs.
3. **Brilliance behind the sequences of GPU rendering** — comparative analysis
   of Redshift, Octane and V-Ray for GPU rendering on Paperspace Core.
4. **Benchmarking GPUs for Mixed Precision Training with Deep Learning** —
   FP16/FP32, automatic mixed precision, CUDA, PyTorch/TensorFlow and A100/V100
   performance considerations.
5. **Computing GPU memory bandwidth with Deep Learning Benchmarks** — GPU
   memory architecture, GDDR generations, theoretical bandwidth and
   STREAM/BabelStream-style measurements.
6. **Understanding Facial Recognition with Deep Learning** — Python-based face
   detection and recognition using dlib, `face_recognition`, NumPy and ResNet
   embeddings.
